# Patitas Felices · página web

Página de la Clínica Veterinaria Patitas Felices (Trujillo). HTML, CSS y JavaScript puros: no necesita instalar nada.

## Estructura

```
patitas-felices-web/
├── index.html        ← la página (todas las secciones)
├── css/styles.css    ← colores, tipografía y diseño
├── js/main.js        ← menú móvil, animaciones, calculadora de vacunas, copiar número
├── fotos/            ← 10 fotos de Unsplash (licencia libre)
└── .vscode/          ← recomienda la extensión Live Server
```

## Cómo abrirla

1. Descomprime la carpeta y ábrela en VS Code: **Archivo › Abrir carpeta…**
2. Instala la extensión **Live Server** (VS Code te la sugiere al abrir la carpeta).
3. Clic derecho en `index.html` › **Open with Live Server**. Se abre en el navegador y se recarga sola cada vez que guardas.

También puedes abrir `index.html` con doble clic, pero las fuentes y los cambios se ven mejor con Live Server.

## Qué cambiar antes de entregar

- **Teléfono / WhatsApp:** busca `944 000 123` y `51944000123` (Ctrl+Shift+H para reemplazar en todos los archivos).
- **Dirección y horario:** busca `Trujillo, La Libertad` y `9:00 a 19:00` en `index.html`.
- **Colores:** están al inicio de `css/styles.css`, en `:root` (`--teal`, `--teal-dark`, `--wa`…).
- **Precios y servicios:** sección `<!-- SERVICES -->` de `index.html`.
- **Vacunas de la calculadora:** objeto `VAC` en `js/main.js`.
